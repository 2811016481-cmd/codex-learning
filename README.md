# 清晰：选照片，自动变清楚，再保存

## 我只想使用

### 电脑免安装版

下载本仓库的 **清晰-双击打开.html** 文件，用 Chrome 或 Edge 浏览器打开。点击「选择要变清晰的照片」，等处理完成，再点「保存清晰图片」。不需要安装 Node.js，也不需要输入任何命令。文件包含所有资源，没有外部字体、图片或脚本。

### 手机和电脑网页版

仓库已经包含可直接发布的单文件网站 `index.html`，不需要构建服务。首次启用需要仓库管理员完成一次 GitHub 设置：

1. 打开仓库 **Settings → Pages**。
2. Source 选择 **Deploy from a branch**。
3. Branch 选择 **qingxi-web**，目录选择 **/(root)**，点击 **Save**。
4. 等待发布完成，点击该页面的 **Visit site**。这个网址在手机和电脑上都能打开，可以收藏。

这会公开工具网页，但**不会上传你的照片**。图片只在自己的设备上处理。若仓库是私有的，GitHub Pages 是否可用取决于账号套餐；以设置页提示为准。发布之后的网站地址以设置页显示为准，不能把代码保存成功视为网站已上线。

部分手机的文件预览器（尤其是 iPhone 的「文件」）不执行网页脚本，手机请优先使用发布后的网站，用 Safari/Chrome 打开。若手机保存按钮没有保存到相册，点击「手机没保存成功？点这里长按保存图片」，再长按照片保存。支持系统分享的手机会弹出分享/保存菜单。

支持 JPG、PNG、WebP。苹果 HEIC 照片需先转 JPG；文件最大 20 MB、输入不超过 4000 万像素且长边不超过 16000 像素。手机输出最多约 300 万像素，电脑最多约 800 万像素，长边不超过 6000 像素，较大图片会适当缩小以避免卡顿。

**效果说明：**本工具使用本地锐化、轻度降噪和插值放大，适合轻微模糊。不是 AI 超分辨率，不能保证恢复严重模糊的人脸或丢失的文字细节。输出为无水印 PNG，保留透明通道。

## 开发维护

以下命令只供开发者维护使用，日常使用不需要。

需要 Node.js 22 或以上，无第三方依赖。

```sh
npm run build  # 根据源文件重新生成两份单文件 HTML
npm test       # 图像算法测试
npm start      # 可选的本地 HTTP 服务，默认端口 3000
```

`template.html`、`style.css`、`app.js`、`image-engine.js`、`processor.js`、`worker.js` 是源文件，修改后运行构建。`build.mjs` 内联所有样式与脚本，并生成内嵌 Blob Worker，不再依赖模块文件加载或服务器。没有 Worker / OffscreenCanvas / createImageBitmap 时，自动使用页面 Canvas 的兼容处理路径。

发布只需 `index.html` 和 `.nojekyll`，也可部署到任意静态网站托管服务；输出 HTML 对子目录没有资源路径依赖。Node 服务带有脚本与样式内容哈希的 CSP，并只提供白名单静态文件。

浏览器验证覆盖：自动增强像素变化、2 倍输出、PNG 下载、手机布局、损坏文件提示、空 MIME 图片、兼容处理路径、长按保存界面，以及 HTTP 加载后断网处理。受当前云浏览器的组织策略限制，直接 file:// 导航在此环境中被阻止；不把该项标为通过。
